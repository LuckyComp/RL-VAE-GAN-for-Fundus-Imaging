# RL-VAE-GAN-for-Fundus-Imaging

## For Setup
- Extract and set up the compressed dataset files the links to which are given below (yet to add).
- Create a venv using the command "python -m venv venv"
- Activate the venv using the command "./venv/Scripts/activate" (for windows) or "./venv/bin/activate" (for linux)
- Install cuda 11.8 as it is a stable compatible release for pytorch
- "pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118"
